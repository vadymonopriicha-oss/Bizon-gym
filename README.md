# Bizon GYM v2

Серверный стартовый проект.

## Запуск
1. Установить Node.js.
2. Выполнить `npm install`.
3. Создать PostgreSQL и выполнить `data/schema.sql`.
4. Скопировать `.env.example` в `.env` и заполнить параметры.
5. Запустить `npm start`.
6. Открыть `http://localhost:3000`.

## Администратор
После создания пользователя в базе данных можно выдать ему роль администратора:
`UPDATE users SET is_admin=true WHERE email='твой-email';`

Админ API уже защищён серверной проверкой роли.

## Важно
Оплата, загрузка файлов и выдача защищённого контента намеренно оставлены отдельным этапом. Для продакшена также нужно включить HTTPS и secure cookies.
